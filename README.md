# Canvas Sprite Sheet Animator

> **Turn sliced sprite sheets into animated Unity UI Images with a simple drag and drop.**

**Canvas Sprite Sheet Animator** is a Unity Editor extension that streamlines the process of creating UI sprite animations. Instead of manually creating an Image, Animation Clip, Animator Controller, and assigning sprites one by one, simply drag your sliced sprite frames into a Canvas and let the tool do the work automatically.

---

## Why Canvas Sprite Sheet Animator?

Creating sprite animations for Unity UI is often repetitive and time-consuming. Unity's default drag-and-drop workflow creates a **SpriteRenderer**, which is ideal for world-space objects but not for UI.

Canvas Sprite Sheet Animator is built specifically for UI development. It automatically converts your sliced sprite frames into an animated **UI Image**, allowing you to build menus, HUDs, effects, icons, and animated interfaces much faster.

---

## Features

* Drag sliced sprite frames directly into a **Canvas**
* Automatically creates a **UI Image** GameObject
* Generates an **Animation Clip**
* Generates an **Animator Controller**
* Automatically assigns all animation frames
* Ready to play immediately
* Works with Unity's built-in UI (UGUI)
* Clean and intuitive workflow
* No scripting required

---

## How It Works

1. Slice your sprite sheet using Unity's Sprite Editor.
2. Select all animation frames.
3. Drag them into a Canvas.
4. Canvas Sprite Sheet Animator automatically:

   * Creates a UI Image
   * Generates an Animation Clip
   * Creates an Animator Controller
   * Assigns all animation frames
5. Press **Play** and your animation is ready.

## Frequently Asked Questions

### Does this work with SpriteRenderer?

No. Canvas Sprite Sheet Animator is designed specifically for Unity UI and creates **Image** components instead of SpriteRenderers.

### Do I need to write any code?

No. Everything is handled automatically through a simple drag-and-drop workflow.

### Can I edit the generated animation?

Yes. All generated assets are standard Unity Animation Clips and Animator Controllers, so you can customize them as needed.
